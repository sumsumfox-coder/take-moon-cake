# 中秋接月餅認字遊戲

一個為特殊教育需要學生設計的中秋節認字練習網頁遊戲。玩家選擇角色後，接住畫面上與目標字相同的月餅，逐字組成「林林總總」一詞，訓練漢字辨識與反應能力。

## 遊戲玩法

1. **選角色**：在首頁選擇兔仔、恐龍或小貓其中一位角色。
2. **接月餅**：畫面上方會顯示本回合的目標字（例如「林」），玩家用鍵盤方向鍵（← →）、A／D 鍵，或畫面上的觸控按鈕左右移動角色，接住寫著目標字的月餅。
3. **組詞進度**：每答對一輪，該字會加入下方的組詞進度列，直到四輪全部完成，組成完整詞語「林林總總」。
4. **生命值**：整局遊戲共用 3 顆愛心，接錯月餅會扣 1 顆，扣完即遊戲失敗。
5. **結算**：
   - 全部答對 → 進入「龍虎榜」，可輸入姓名依完成時間排名。
   - 中途失敗 → 進入「遊戲失敗」畫面，可選擇再玩一次或返回主頁。

## 技術架構

- 純前端單一 HTML 檔案，內嵌 CSS 與 JavaScript，無需伺服器即可執行。
- 使用 Tailwind CSS（CDN）處理版面樣式，Lucide Icons（CDN）提供圖示。
- 遊戲主迴圈以 `requestAnimationFrame` 驅動月餅掉落與碰撞偵測。
- 使用瀏覽器原生 `SpeechSynthesis` API 朗讀目標字（粵語 `zh-HK`），輔助認字與發音學習。

## 開發過程中修正的問題

本專案原始版本存在數個影響遊戲可用性與教學效度的缺陷，修正記錄如下：

| 問題 | 原因 | 修正方式 |
|---|---|---|
| 勝利／失敗畫面完全不會跳轉 | `<h1 data-template-id="result-title">` 遺漏了真正的 `id="result-title"` 屬性，導致 `finishGame()` 執行 `getElementById("result-title").classList` 時對 `null` 取值拋出例外，中斷整個結算流程 | 補回缺漏的 `id` 屬性，並新增 `el()` / `safeText()` / `safeToggle()` 輔助函式，即使個別元素查詢失敗也不會讓結算流程中斷 |
| 遊戲卡住不動、月餅停止掉落 | `gameLoop()` 以 `requestAnimationFrame` 遞迴呼叫自己，若函式中途拋出任何未攔截例外，結尾的重新排程就不會執行，整條動畫迴圈會靜默死亡且無法自行恢復 | 將 `gameLoop()` 主體包入 `try/catch`，確保任何例外都不會中斷下一幀的排程；另外新增「看門狗」機制，每秒檢查迴圈心跳，超過 1.2 秒無回應即自動重啟迴圈 |
| 每輪重置愛心，失敗機制形同虛設 | `beginRound()` 每次開始新回合都重設 `hearts = 3`，導致玩家只要單輪內不連續答錯 3 次就不會失敗 | 愛心改為整局遊戲共用，只在 `startGame()` 初始化一次，不在回合切換時重置 |
| 組詞進度提前洩漏答案 | 進度顯示邏輯對「第一個字」有特殊處理，導致遊戲一開始就顯示答案而非底線 | 改為單純依「是否已收集」判斷，未收集一律顯示 `_` |
| 正確答案出現機率過低、可能連續掉落多個干擾字 | 月餅生成機率固定 36%，且沒有防止玩家長時間等不到正確答案 | 加入 4.5 秒逾時保護，若太久沒出現正確答案會強制生成一個，降低學生挫折感 |
| 語音朗讀可能因裝置缺少語音包而拋出未攔截例外 | `speakWord()` 原本沒有例外處理 | 加上 `try/catch` 與 `onerror` 空處理，語音失敗不影響遊戲其餘功能 |

## 已知限制

- 目前詞語固定為「林林總總」，如需更換教學內容，需同步修改 `targetWords` 陣列與 `distractorWords` 干擾字庫。
- 龍虎榜排名資料僅存在瀏覽器記憶體中，重新整理頁面後會清空，如需長期保存學生成績，需額外串接後端或本機儲存（如 `localStorage`）。
- 語音朗讀仰賴使用者裝置的系統語音包，若裝置未安裝粵語語音包，該功能會靜默失效但不影響遊戲進行。

## 測試方式建議

1. **勝利路徑**：連續接對四輪正確的字，確認畫面跳轉至龍虎榜並可輸入姓名。
2. **失敗路徑**：故意連續接錯三次（同輪或跨輪皆可），確認畫面跳轉至失敗頁。
3. **重玩流程**：於結算頁按「再玩一次」，確認分數、愛心、組詞進度皆正確重置。
4. 建議開啟瀏覽器開發者工具（F12）的 Console 分頁一併觀察，若出現看門狗自動重啟的警告訊息，代表仍有邊界情況觸發例外，可將訊息回報以便進一步排查。
